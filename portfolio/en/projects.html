Workflow Generator

Live Demo GitHub

A documentation automation tool that structures text-based workflow descriptions into SwimLane diagrams and Word manuals.

Motivation

Visualizing business processes and managing them as documents was time-consuming and tedious.
Designed to reduce manual drafting from 30–40 minutes to under 5 minutes per process (benchmarked on 5 sample workflows), and validated the end-to-end flow from input → structuring → diagram → Word output.

▶Key Features · Architecture · Problem Solving

Key Features

AI Auto-Structuring

Claude API analyzes text descriptions and automatically converts them into department, group, process, and step structures.

SwimLane + LinearFlow

Renders SwimLane diagrams showing department roles at a glance and LinearFlow diagrams showing step-by-step flows in SVG.

Auto Word Manual

Generates .docx documents with cover page, summary table, step details, and images directly in the browser.

Drag & Drop Editing

Step reordering with @dnd-kit, parallel branching (colIndex) support for intuitive editing of complex processes.

Netlify Functions

React SPA

LocalStorage (text) IndexedDB (images)

Problem Solving

Problem

AI structures text into sequential steps, but real workflows often have parallel flows like "A and B run simultaneously" that can't be represented as simple lists

Solution

Assigned colIndex (column number) to each step to auto-group same-column steps as parallel branches, with @dnd-kit drag-and-drop for intuitive order and branch editing

React 18 Vite SVG Claude API Netlify Functions docx @dnd-kit IndexedDB

AI Project Kickoff Harness

GitHub

A CLI automation harness that transforms vague project ideas into development-ready plans through AI-driven interviews and validation. Converts ideas into actionable requirement documents via structured interview flows, Gap Check, and checklist generation.

Motivation

Every time I started a new project, unclear requirements led to repeated redesigns mid-development. I wanted to build a tool where AI conducts structured interviews to turn vague ideas into well-organized planning documents before writing a single line of code. This harness was used to validate the planning of my other side projects, proving its practical value.

Showcase

finance_data_platform Snowflake + Power BI + Text-to-SQL AI finance data analytics platform Kickoff Doc
Prequel Web SaaS version of this harness — AI structured interviews in the browser Kickoff Doc
▶Key Features · Architecture · Problem Solving

Key Features

Multi-Skill Chaining Pipeline

Skills auto-chain in sequence: context → start → interview → suggest → profile → evaluate → gap → checklist → done → skills.

Dogfooding Self-Validation

Over 3 rounds of dogfooding, discovered and fixed 10+ design flaws in input flows, evaluation criteria, missing questions, and checklist structure.

4+2 Dimension Honest Evaluation

Evaluates project feasibility across 4 base dimensions (technical, market, learning, completion) + 2 conditional dimensions (learning cost, security).

Gap & Contradiction Detection

AI automatically identifies missing requirements and contradictory designs in planning documents before development begins, reducing redesign costs.

Problem Solving

Problem

Missing requirements and contradictions in planning documents were only discovered during development, causing costly redesigns

Solution

Built a kickoff-gap skill that automatically detects contradictions (e.g., feature-tech stack mismatches) and gaps (e.g., undefined non-functional requirements) before development. Validated the harness itself through 3 rounds of dogfooding

AI Stock Analyzer

Live Demo GitHub

An experimental stock analysis project designed to separately collect real-time financial data and news summaries, with multiple AI agents generating evidence-based reports.

Motivation

When analyzing stocks, having to check prices, financials, news, and macro data across multiple platforms felt inefficient. Rather than querying a single AI, I wanted to design and implement a multi-agent architecture where 5 specialized agents analyze from different perspectives and cross-validate each other's findings.

▶Key Features · Architecture · Problem Solving

Key Features

Quick Look

Instantly retrieve real-time prices, candle charts, financial metrics, and technical indicators (MACD, Bollinger Bands) within 1 second.

5-Agent Deep Analysis

News, Data, Macro, Cross-Validator, and Analyst agents run in parallel, cross-validate findings, and deliver BUY/HOLD/SELL recommendations.

7 APIs + Fallback Chain

Integrates yfinance, Finnhub, Twelve Data, Finviz, FMP, FRED, and Claude API. Automatically tries alternative sources when the primary API fails.

Anti-Hallucination Design

All numbers come from APIs only; AI handles interpretation only. Role separation ensures reliability in the financial domain.

Problem Solving

Problem

Frequent 403 errors from external data APIs' free plan limits causing analysis to break

Solution

Built a multi-fallback chain (yfinance → Finviz → FMP) and applied Graceful Degradation per agent, so the remaining analysis continues even when one source fails

React TypeScript FastAPI Claude API SQLite yfinance Lightweight Charts asyncio
